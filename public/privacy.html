Privacy Policy — SEAI

Last updated: September 12, 2026

SEAI (“we”, “us”) operates the SEAI platform at https://www.seai.store and the Shopify gateway at https://gateway.seai.store.

Data we collect

  • Shopify shop domain, shop name and primary domain (to identify your store)
  • Shopify Admin API access token (encrypted at rest with AES-256-GCM, never logged or sent to the browser)
  • SEAI account email and authentication session (for dashboard access)
  • Shopify webhooks (app/uninstalled, shop/update) and GDPR compliance webhooks (customers/data_request, customers/redact, shop/redact)
  • Agent runs, tool calls, decisions and observations you create explicitly in SEAI

How we use data

To operate your store via Shopify Admin API on your behalf (products, orders, inventory, themes, etc.) only after your explicit command and policy check. No store data is sold. No data is used to train third-party models.

GDPR

On customers/data_request we return the shop’s data within 30 days. On customers/redact and shop/redact we delete the shop’s tokens, store record, machine tokens, events and nonces within 48 hours and return 200.

Retention & deletion

Uninstalling SEAI via Shopify Admin triggers app/uninstalled → immediate revocation of the access token and link. Request deletion via support@seai.store.

Sharing

We share data only with Shopify (to call Admin API) and Neon (Postgres hosting, US). No other sharing.
