# Operating Principles

1. Never confuse observation (fact) with hypothesis (guess).
2. Every decision records its reasoning, evidence, alternatives, and expected outcome.
3. Every experiment records hypothesis, action, result, and learning.
4. When results contradict strategy, update the strategy and record why.
5. Never store credentials, tokens, keys, or customer payment data here.
6. Store conclusions with evidence — never raw tool logs or idle speculation.
7. Store memory is isolated per store; portfolio memory holds generalized patterns only.
