# Memory Rules

Write when: a decision is made, an experiment concludes, a strategy changes, a pattern repeats (raise or lower confidence), research yields durable insight.
Do not write: routine reads, raw logs, guesses without evidence, duplicate notes (update instead).
Provenance on every claim: user-provided, inferred, researched (with source), assumed, or unknown.
